## 2. 输入

之前 bot 只能看文字。这两周补齐了三种"输入"：

- **图片**：Telegram 直接发图给它，它能看见。依赖模型能力
- **引用消息**：在 Telegram"回复"某条历史消息时，AI 能看到被引用的那段
- **链接内容**：扔小红书 / B 站 / YouTube / 普通网页链接，bot 会读进来再聊。（不稳定，依赖浏览器 cookie 登录态）

## 4. 拟人

### 增加intersts档位

原来只有 casual / empathy / depth 三档。用户分享游戏、番剧、刚发现的酷事等高能量正向场景时，落到 casual 档——指令块为空，LLM 靠 system prompt 里"遇到喜欢的话题会变活"的一句话被动感知，没有专门的指令强制"接住"能量。实测容易扫兴（平淡应答、分析拆解、语气降温）。

### 人格演化

用户接得住毒舌它会更皮；用户最近多走心它也会更软；停一阵不聊又会慢慢回到中性。它有"内心状态"——心情、自我观察、跟你的小锚点——但**不会主动跟你说**"我变了"，是藏着自己知道。
预期希望此系统能够根据用户不同从而发展出每个用户相对独一无二的bot，目前此系统为初步尝试，还是以system prompt为锚点，理论上无法做到千人千面。
比较可能性的方向为动态prompt工程，待探索

增加内心状态层：
- **traits**：5 个维度的连续值（-1..1），从中性向某方向小幅漂移
- **mood**：当下心情一句话
- **observations**：从 AI 第二人称视角的自我观察（"你这两天话变少了"）
- **milestones**：和对方相处的小锚点（第一次提家人、走心夜聊等），永久保留

| key             | 含义           | 用户的何种反应会推动它        |
| --------------- | ------------ | ------------------ |
| `sarcasm`       | 玩笑/毒舌强度      | 接得住 → +；皱眉/转话题 → - |
| `warmth`        | 温柔/共情成分      | 走心倾诉多 → +；冷淡 → -   |
| `verbosity`     | 话密度（负=更短促）   | 用户铺开 → +；敷衍/短促 → - |
| `assertiveness` | 主动给观点（vs 倾听） | 问观点/反问"你怎么看" → +   |
| `curiosity`     | 好奇/挖话题       | 新话题被接住 → +         |

## 5. 其他细节调整
### 时间感
现在它知道几点几号、星期几、是工作日还是周末、距离上次聊多久。
回复里会听到它说"这都两天没聊了""刚过晚饭点""那个点你还没睡"——而不是"现在是 14:32"。

### 表情包
往本地图库放图（文件名当语义标签——`无奈.jpg`、`大笑.png`、`加油.gif`），它觉得当下"发表情比文字对劲"时会自己挑一张发。空库时不知道有这功能，零侵入。

### 对话风格连续打磨
- "认真聊"模式：之前太"端"（"建议""首先其次""可以考虑"那种），重写指令变成"想法碰撞，不追求周全"
- 节奏：长话拆几条发、不刻意拆条，把"短回复多条 / 长论述一段"分开处理
- 引导：默认不反问，用陈述句邀请话题延续
- 默认禁用一批助手词（"建议你""希望对你有帮助""根据..."）

## 6. 让 AI 主动开口

**之前主动阈值过高**，表现为几乎不会主动触达用户，现在会了。

- 删了"23-7 点一刀切不发"的硬限制——交给软门 LLM 看你历史活跃时段判断。
- 频率提到一天最多 6 条，每两条之间至少 90 分钟间隔。
- 发出的不是定点问候，而是"刚好想到一件事"——会猜用户此刻可能在做什么，挑合适的角度切入。

## 6. 调试 / 运维基础

### 审计日志可视化
新搭了一个 Web UI（http://127.0.0.1:18081 ，原本只看记忆，现在加了"审计"tab）：

- 实时看 bot 跟用户的每一轮：用户说了什么、AI 回了什么、用了哪个模型、多快、调没调记忆、激活了哪些工具
- 看人格变化：每次 trait 微调、新增的自我观察、跟你的共同锚点
- 看主动搭话决策：什么时候想发、判断为啥不发、最终发出去的话
- 5 秒自动刷新，按事件类型筛选

不依赖 LLM，纯结构化日志，方便事后复盘和找问题。
