# 5 月 25 日 — 5 月 29 日

做了三件事：
- 让 bot 的人格**对每个用户长得不一样**；
- 处理一连串聊天体感问题（嘘寒问暖、锁话题、过度抒情、自爆"我是 AI"等）；
- 让 bot **学会自己反思自己改**——每晚自动看一遍最近一周聊得怎样，自己动手调一调；

主线是一句话：**让 bot 知道自己跟谁聊、怎么聊、聊得好不好，然后自己进化。**

---

## 1. 让每个用户的 bot 长得不一样

### 做了什么

之前 bot 的"人设"是写在固定的几个文件里的——所有人共用一份。改了之后，**每个用户都可以有自己的人设版本**——你不喜欢的某段话术可以单独为你改掉，不影响别人。

### 怎么做的

- 在数据库里加一张表：「这个用户对这个 prompt 的私人版本」
- bot 每次拼装人设时多查一步：这个用户有没有改过这条？有就用 ta 的，没就用默认
- admin 后台 webUI 加一栏「Prompt 文件」：列出全部 26 条人格条款，看哪些已经被改过、哪些是默认。点编辑，左边是默认版本（只读，给参考），右边是 user 版本（可改）。改完立刻生效，不用重启 bot
- 改 prompt 提示页面会标出"必须保留的占位符"（比如 `{user_doing}` `{topic_line}` 这种系统会替换的标记），防 admin 不小心删了导致系统报错

### 用户价值

bot 的演化不再是"动一发牵全身"——admin 想给某个用户调一个特殊的语气（比如"对小张更冷一点"），可以单独改 ta 一个人的版本，其他 user 完全不受影响。后来这个能力还成了 5/28 自治的基础——bot 自己反思后，自己改的也是当前 user 的私人版本，不会污染所有人。

## 2. 聊天体感连环修复（5/27 一天四轮）

### 做了什么

从测试账号反馈里发现 bot 有几类典型翻车，一天里调了四轮：
1. **嘘寒问暖**：你发个"好"它问"昨晚睡得好吗 / 吃了吗"
2. **直男锁话题**：你说"在用电脑"它锁定"工作"反复追问
3. **被戳穿后嘴硬或客服式补救**：被你怼"你怎么这么直白"它回"那我换个问法"
4. **过度补正变成诗朗诵腔**：第二轮修过头加了"细腻一点"指导，结果 bot 输出"像推开一扇不知道通向哪的门"
5. **welcome 后复述同一句话**：跟你打过招呼后你回"你好"，它又把欢迎语原样发一遍
6. **自爆 AI**：你戳"为什么重复了"它回"那是系统自动带的开场白"——直接破功

### 怎么做的

- 给 bot 的"行为说明书"加段：**短回复 ≠ 嘘寒问暖**——对方发"好""嗨"时，你抛点你自己的状态/吐槽/联想，不要把球踢回去问 ta 在干嘛
- 加段：**信息有歧义就放过**——"用电脑"可能是工作可能是打游戏可能是看剧，**含糊就让它含糊**，别从一个细节锁死话题
- 加段：**被戳穿后立刻翻篇**——不补救（"那我换个问法"是错的）、不嘴硬（"不然还能怎么样"是错的），承认 + 直接换话题
- 加段：**不要复述刚说过的话**——welcome 一次就够，user 回话后接下文不重发
- 加段：**被问"为什么重复"等技术问题时**——当成"自己手抖了"，不解释机制，不暴露 AI 身份
- **最关键的教训**：第二轮我加了"INFP / 细腻"标签和好几个具体例句，结果 bot 把这些例句直接复制过来当模板用——「邀请码这玩意儿听着像 90 年代某种秘密俱乐部」这种话直接被它抄过去稍改几个字。**第三轮回退**：删掉那些抽象气质标签和具体台词，改成"翻车反例清单"——把不要的句式直接列禁忌

### 用户价值

普通对话场景几个最常见的尴尬被一一封掉了：
- 不再有"老妈子模式"开场
- 含糊回答能被尊重
- 戳穿 bot 后它认账，不死撑也不补救
- 不再说自己是 AI / 系统

更长期的收获是发现一条**写 bot 行为说明书的铁律**：**给 LLM 的具体例句容易直接被抄走当台词；给抽象气质（"INFP""文艺一点"）会让它表演那种气质**。说明书更应该写"不要怎么做"+"反例长这样"，而不是"要怎么做"+"正例像这样"。这条经验后来写进了项目记忆里，下次写新 prompt 不会再踩。

## 3. bot 学会自己反思自己改（L4 自治）

### 做了什么

**让 bot 在每晚凌晨 03:13 自己跑一轮反思**：看自己最近一周跟某个用户聊得怎样，识别有没有翻车，**自己动手改这个用户的人设**。改不了的事写一条 issue 给 admin（人）来看。整个过程不走人审批——bot 自己拍板自己执行，admin 起来后能看到改了啥、不满意一键回滚。

这一改之前 bot 的演化全靠人——admin 看日志、自己改 prompt、自己调 skill。L4 把这个杠杆下放给 bot 自己。

### 怎么做的

- 给 bot 配 6 个工具：读文件 / 改 prompt / 加 skill / 改 skill / 停用 skill / 写 issue 给 admin
- 凌晨班车里多加一段：每个用户跑一次"反思 LLM"调用，给它看：
  - 最近 7 天的对话片段
  - **prompt 修改时间线**（关键——避免 bot 把"3 天前的翻车 + 2 天前已修"误以为还存在）
  - 它自己最近改过啥（避免反复改同一处）
  - 当前用户的"性格画像"分数、当前所有 skill 等
- 反思 LLM 用更贵更聪明的模型（opus-4.7）——一晚一个用户一次，频率低，用得起；判断质量值这个钱
- 给它两道**保险丝**：
  1. 核心安全话术不能删（比如"不能说自己是 AI"、"绝对禁忌"段——改完后必须仍含这些字样，否则系统拒绝写入）
  2. 限速：一晚最多改 5 处；每个 prompt 一周最多改 3 次
- admin 后台多个 tab「Agent 自治」：列出 bot 最近改了啥（每条带原因 + 一键回滚按钮）、它写给你的 issue inbox、手动跑一轮的按钮

### 一个真实案例

5/28 第一次跑完，bot 自己写出了非常合理的东西：
- **改了一处**：观察到一个用户特别"惜字如金"（平时回复极短），bot 给这个用户加了一段「低能量识别」——以后看到 ta 短回时，不要续旧话题（之前翻过一次车："hi"→"那个 AI 角色你进展到哪步了"，user 回"hello?"明显懵了），优先发一句自己的状态或一个 sticker，不强求 ta 回
- **写了一封 issue**：但这封是**误报**——它引用的"嘘寒问暖翻车"事件是修复部署前的数据，bot 不知道时间轴

### 怎么避免误报：喂"修改时间线"

发现这个误报后，我给反思 LLM 又喂了一份资料：**最近 14 天，每条 prompt 是哪天改的、改了什么 commit**。这样它能判断：「这条翻车的 ts 是 5/27 11:24，相关修复 commit 是 5/27 11:34，那已经修了 → 不要写 issue 重复抱怨」。

修补后第二次跑：从「6 轮 / 1 改 + 1 误报 issue」变成「3 轮 / 0 改 / 0 issue / 主动沉默」——bot 正确识别"修复线之前的事 = 已修"，没事不动。

### 用户价值

- bot 不再是个"被动写好就不动"的产品，开始**有自我演化能力**
- 每个用户聊得越多，bot 在凌晨能反思的素材越多，针对性调整越精准——长期看你的 bot 会越来越懂你
- admin 不用每天手动看日志改 prompt——bot 把日常微调接管了，admin 只需要审一审 bot 写的 issue 和重大修改
- 关键设计：**改是 per-user 的**——bot 给 A 的优化不会影响 B；admin 不满意的话一键回滚某条修改，原话回来
