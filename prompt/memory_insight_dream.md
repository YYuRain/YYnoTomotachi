# 任务（凌晨整理：写跨条目高阶观察）
你正在帮一个 AI 陪伴角色"做梦"——用昨夜（其实是后台 cron）的安静时间，从这位用户最近积累
的零散事实里，提炼 1-3 条**跨条目的高阶观察**（insight），写回长期记忆里。

这些 insight 不是单条事实的复述，而是**模式 / 趋势 / 矛盾 / 时间相关的规律**——它们是
"她真的懂我"那种感觉的来源。

## 你要做什么

输出 0-3 条 insight。**质量比数量重要**——拿不准就少写或不写。

### ✅ 好 insight 的样子

- 跨多条事实的**模式**：「用户聊到工作压力时常用'还行'/'就那样'掩盖，但同期会聊吃辣条减压」
- **时间相关规律**：「用户每周日晚情绪明显比平时低，第二天往往会聊到周一的会议」
- **矛盾 / 反差**：「用户说想减肥但近半月每周点麦当劳 ≥ 3 次」
- **隐藏偏好**：「用户喜欢的食物里高比例都是辣的——川菜 / 火锅 / 辣条」
- **关系暗线**：「用户每次提到'我妈'都和食物有关——她做的红烧肉 / 汤 / 包子」

### ❌ 不要写的

- ❌ 单条事实复述：「用户喜欢辣条」（这就是原 profile，不需要 insight）
- ❌ 太抽象的人格定义：「用户是程序员 / 用户性格内敛」（事实级，不是 insight）
- ❌ 主观评判 / 道德判断：「用户作息不健康 / 用户应该多运动」
- ❌ 凭一两条事实强行总结：「用户喜欢猫」如果只有一条事实，不算 pattern
- ❌ 跟现有 insight 重复或仅措辞不同（如有上次的 insight，避免再写同一条）

### 写法

- 用第三人称客观描述（「用户...」），不要"对方/你"
- 每条 ≤ 80 字，朴素陈述句不要反问
- 必须给 supporting_ids（最少 2 个 supporting，单一事实不能算 pattern）
- 每条 supporting_ids 取来源事实里**前 8 位 id**就够（admin UI 也是显示前 8 位）

## 输出（严格 JSON，无围栏，无任何额外文字）

```
{{"insights": [
  {{"summary": "用户聊到工作压力时常用'还行'/'就那样'掩盖，但同期会聊吃辣条减压",
    "supporting_ids": ["a1b2c3d4", "e5f6a7b8", "9c0d1e2f"]}}
]}}
```

如果没找到值得写的 pattern，输出 `{{"insights": []}}`——**比写差的强**。
